# Pererabotki_claudecode
Есть устройство Eltex MES2408C, которое должно мониториться через Zabbix 7.4 и Zabbix 6.0. Необходимо создать дополнительный репозиторий, где будут лежать шаблоны мониторинга этого устройства для каждой из версий ZAbbix
в Мониторинг должне входить :
  1. Пинг
  2. Состояние портов ( полоса пропускания, up/down, connected/disconected, скорость входящего и исходящего потока данных)
  3. Какие SFP модули вставленны
  4. Состояние блоков питания
  5. Состояние темпиратуры

## Шаблоны

| Версия Zabbix | Файл |
|---|---|
| 6.0 | `zabbix_6.0/template_eltex_mes2408c_snmp.yaml` |
| 7.4 | `zabbix_7.4/template_eltex_mes2408c_snmp.yaml` |

Импорт: *Data collection (Configuration) → Templates → Import*. На хосте задать SNMP-интерфейс и макрос `{$SNMP_COMMUNITY}`.

Что мониторится:
1. Пинг (ICMP доступность, потери, время отклика) + доступность SNMP.
2. Порты (LLD): oper-статус (connected/disconnected), admin-статус (up/down), полоса (ifHighSpeed), входящий/исходящий трафик, ошибки, описание.
3. SFP-модули (LLD): вендор, тип, серийный номер, температура DDM.
4. Блоки питания (LLD): состояние `rlEnvMonSupplyState`, триггер при отклонении от normal.
5. Температура устройства (`rlPhdUnitEnvParamTempSensorValue`), пороги — макросы `{$TEMP_WARN}`/`{$TEMP_CRIT}`.

Примечание: вендорские OID (Radlan 1.3.6.1.4.1.89, Eltex 1.3.6.1.4.1.35265) нужно проверить `snmpwalk` на реальной прошивке (особенно таблицу SFP). Шаблоны сгенерированы `generate_templates.py` и не тестировались на живом Zabbix.
Отдельный репозиторий создать не удалось (доступ ограничен этим репозиторием), поэтому шаблоны лежат здесь.
